# OpenTask Backend AI Coding Rules (`api/AGENTS.md`)

This document outlines the strict guidelines and conventions for backend API development within the `api/` workspace.

---

## 1. Toolchain: UV Exclusively

- **Mandatory Package & Environment Manager**: **UV** (`uv`) is the official package manager, virtualenv runner, and dependency resolver for the Python API.
- **Rules**:
  - Run `uv sync` to synchronize the environment with `pyproject.toml` and `uv.lock`.
  - Run `uv pip install <package>` when installing new Python dependencies.
  - Run `uv run uvicorn src.main:app --port 8000 --reload` to start the local development API server.
  - Run `uv run python <script>` or `uv run pytest` to execute scripts and test suites.
  - **Do NOT execute bare `python`, `pip install`, or create unmanaged virtual environments.**

---

## 2. Architecture & Directory Layout

- **`src/main.py`**: FastAPI application entry point, CORS configuration, lifespan events, and router registration.
- **`src/config.py`**: Pydantic `BaseSettings` reading environment variables (`.env`, `.env.prod`).
- **`src/routers/`**: HTTP endpoint controllers (`auth.py`, `github.py`, `tasks.py`, `meetings.py`, `telegram.py`, `notifications.py`).
- **`src/services/database/`**: PostgreSQL database access layer:
  - `database.py`: Thread-safe connection pool (`ThreadedConnectionPool`), `_get_conn()`, `_put_conn()`, `SafeId` type.
  - `id_generator.py`: Twitter Snowflake ID generator (`_generator.generate()`).
  - Table-specific services (`tasks.py`, `projects.py`, `buckets.py`, `alerts.py`, `github_installations.py`, `pr_reviews.py`, `history.py`).
- **`src/services/notifications.py`**: Background push notification worker and alert dispatcher.
- **`src/services/gemini_code_review.py`**: Google Gemini AI code review engine triggered by GitHub pull request webhooks.

## 3. Core Coding Patterns

### 3.1 Database Connection Leasing (Connection Pool Pattern)
Never hold persistent raw connections or leave connections unreleased. Always lease from the pool and return in a `finally` block:

```python
import psycopg2
import psycopg2.extras
from fastapi import HTTPException
from services.database.database import _get_conn, _put_conn

def get_or_update_record(record_id: int):
    conn = _get_conn()
    cur = None
    try:
        cur = conn.cursor(cursor_factory=psycopg2.extras.RealDictCursor)
        cur.execute(
            "SELECT id, title, created_at FROM opentask.tasks WHERE id = %s;",
            (record_id,)
        )
        row = cur.fetchone()
        if not row:
            raise HTTPException(status_code=404, detail="Task not found")
        conn.commit()
        return row
    except HTTPException:
        conn.rollback()
        raise
    except Exception as e:
        conn.rollback()
        raise HTTPException(status_code=500, detail=str(e))
    finally:
        if cur is not None:
            cur.close()
        _put_conn(conn)
```

### 3.2 Snowflake SafeId & BigInt Serialization
- All primary keys in PostgreSQL are `BIGINT` (64-bit integer) generated by `_generator.generate()`.
- **JSON Serialization Rule**: Because standard JSON parsers and JavaScript round numbers larger than \(2^{53} - 1\), all Snowflake IDs returned to the frontend MUST be converted to `str` or wrapped with `SafeId`:
  ```python
  from services.database.database import SafeId

  class TaskResponse(BaseModel):
      id: SafeId
      project_id: SafeId
      bucket_id: SafeId
      title: str
  ```
- In database queries, coerce input values to integer for SQL parameter binding:
  ```python
  cur.execute("SELECT * FROM opentask.tasks WHERE id = %s;", (int(task_id),))
  ```

### 3.3 Safe Database Migration Pattern
When creating or modifying database schema, use `CREATE TABLE IF NOT EXISTS`, `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`, and `CREATE INDEX IF NOT EXISTS` in the service initialization routine or `init_db.sql`:
```python
def init_service_table():
    conn = _get_conn()
    cur = None
    try:
        cur = conn.cursor()
        cur.execute("""
            CREATE TABLE IF NOT EXISTS opentask.example_table (
                id BIGINT PRIMARY KEY,
                created_at TIMESTAMPTZ DEFAULT NOW()
            );
            CREATE INDEX IF NOT EXISTS idx_example_created ON opentask.example_table(created_at);
        """)
        conn.commit()
    except Exception as e:
        conn.rollback()
        logger.warning(f"Error creating table: {e}")
    finally:
        if cur is not None:
            cur.close()
        _put_conn(conn)
```

### 3.4 API Prefix and Middleware Awareness
- `main.py` contains `StripApiPrefixMiddleware`. Both `/api/tasks` and `/tasks` route to the same underlying handler, ensuring smooth compatibility between local Docker development and Vercel serverless deployment.
- Avoid double `/api/api/` prefixes when declaring router routes.

## 4. Pre-Commit Checklist
Before completing any backend API task, verify:
- [ ] Validated with `uv run python -m py_compile <modified_files>`.
- [ ] Tested imports and startup via `uv run python -c "import main"`.
- [ ] Every database connection opened with `_get_conn()` is released in a `finally: _put_conn(conn)` block.
- [ ] All BigInt Snowflake IDs are returned as strings / `SafeId` in JSON responses.
